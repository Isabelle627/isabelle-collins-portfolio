# Isabelle Collins — Portfolio Website

A responsive, static portfolio website with three pages and a click/tap interactive flower garden. The album cover and creative-studio process assets are based on the user's prior project files available in ChatGPT Library.

## Preview locally
Open `index.html` in a web browser. Keep the `assets` folder alongside the HTML files.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `portfolio` (or another name you prefer).
2. Upload all files and the `assets` folder from this package to the repository's root. Do not upload only the HTML files.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish. The public URL will look like `https://YOUR-USERNAME.github.io/portfolio/` (use the exact URL GitHub shows).
6. Open that URL in a private/incognito window and test both project links, images, and the click/tap flower interaction.
7. Submit the live homepage URL in Canvas and post the same link in the course discussion.

## Before submitting
- Confirm the name and project descriptions are accurate.
- The available studio file is a concept/process board, not a camera walkthrough video. If you have a separate final 3D render or walkthrough video, replace/add it in the creative studio page before publishing.
- If the course requires a separate final 3D render, use your original final render in place of `assets/creative-studio-revised.png`.
